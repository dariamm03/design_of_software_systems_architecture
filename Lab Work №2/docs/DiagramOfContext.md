1. Система мониторинга и анализа логов  
   Централизованная система, которая собирает, обрабатывает и анализирует логи различных приложений и систем. Основная задача — предоставление информации о состоянии и производительности системы.
2. Elasticsearch  
   Поисковая и аналитическая платформа, используемая для хранения и индексирования логов. Позволяет быстро выполнять запросы и находить необходимые данные для анализа.
3. Grafana  
   Инструмент для визуализации данных, который подключается к Elasticsearch. Позволяет создавать интерактивные панели и графики, помогая пользователям лучше понимать состояние системы в реальном времени.
4. Telegram bot  
   Бот, который уведомляет пользователей о событиях и аномалиях в системе. Он может отправлять сообщения пользователям о важных событиях, которые требуют внимания.
5. Сервер заказчика с БД  
   Узел, на котором размещены базы данных заказчика. Система мониторинга может взаимодействовать с этой базой данных для получения необходимой информации или для хранения логов и отчетов.
