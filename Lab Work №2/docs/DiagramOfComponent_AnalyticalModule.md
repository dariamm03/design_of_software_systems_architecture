1. Модуль машинного обучения
   - Отвечает за анализ данных и построение предсказательных моделей. Этот компонент включает в себя основные алгоритмы и обученные модели, которые обрабатывают входные данные.
2. Модуль формирования отчетов
   - Генерирует отчеты на основе анализа данных и результатов работы модуля машинного обучения. Он может адаптироваться под разные форматы вывода (например, pdf, excel) и предоставляет пользователям структурированную информацию.
3. Модуль обработки данных
   - Обрабатывает и подготавливает входные данные для модуля машинного обучения. Этот компонент выполняет задачи очистки, трансформации и агрегации данных, обеспечивая их соответствие необходимым требованиям.
4. Чат-бот API
   - Обеспечивает взаимодействие между пользователем и системой. Через API пользователи могут запрашивать данные, получать результаты анализа, а также управлять процессом формирования отчетов.
