Сборщик логов
Компонент, ответственный за агрегацию логов из различных источников, таких как серверы, приложения или системные журналы. Он может использовать различные протоколы (например, Syslog, HTTP) для получения данных в реальном времени или через периодический опрос.
Обработчик
Этот объединённый компонент выполняет следующие задачи:
Сбор логов
Фильтрация и нормализация данных
Парсинг данных в удобный формат
Создание метрик и сведений для визуализации
Подготовка финальных данных для отправки в Elasticsearch


Система мониторинга и анализа логов
Централизованная система, которая собирает, обрабатывает и анализирует логи различных приложений и систем. Основная задача — предоставление информации о состоянии и производительности системы.

Elasticsearch
Поисковая и аналитическая платформа, используемая для хранения и индексирования логов. Позволяет быстро выполнять запросы и находить необходимые данные для анализа.

Аналитический модуль
Основной компонент, отвечающий за обработку и анализ данных. Он выполняет сложные запросы к данным, получает события в реальном времени и принимает решения на основе анализа.
