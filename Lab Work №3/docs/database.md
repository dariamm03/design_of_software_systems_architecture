1. User (Пользователь)
   - id: уникальный идентификатор пользователя.
   - username: имя пользователя, используемое для входа.
   - email: адрес электронной почты пользователя.
   - password: зашифрованный пароль для аутентификации.
   - created_at: дата и время создания учетной записи.

   Хранит информацию о пользователях системы.

2. Action (Действие)
   - id: уникальный идентификатор действия.
   - action_type: тип действия (например, "login", "logout", "update_profile").
   - description: описание действия, которое полезно для логирования.

   Задает различные типы действий, которые могут выполнять пользователи.

3. Log (Журнал)
   - id: уникальный идентификатор записи в журнале.
   - user_id: ссылка на пользователя, который выполнил действие.
   - action_id: ссылка на действие, которое было выполнено.
   - timestamp: дата и время выполнения действия.
   - ip_address: IP-адрес пользователя, с которого выполнялось действие.

   Записывает конкретные действия пользователей с привязкой к времени и детали о подключении.

4. Session (Сессия)
   - id: уникальный идентификатор сессии.
   - user_id: ссылка на пользователя, который инициировал сессию.
   - session_token: уникальный токен сессии для идентификации.
   - created_at: дата и время создания сессии.
   - expired_at: дата и время истечения срока действия сессии.

   Отслеживает активные сессии пользователей для управления безопасностью и доступом.

5. Error (Ошибка)
   - id: уникальный идентификатор ошибки.
   - error_code: код ошибки, который может помочь в диагностике.
   - error_message: текстовое сообщение, объясняющее ошибку.
   - timestamp: дата и время возникновения ошибки.
   - user_id: ссылка на пользователя, который столкнулся с ошибкой (может быть пустой, если ошибка не связана с пользователем).
